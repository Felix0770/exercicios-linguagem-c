# Exercícios de Programação em C

Este repositório reúne exercícios e atividades desenvolvidos durante meus estudos de programação em linguagem C, no curso de Banco de Dados.

Os exercícios foram organizados por assunto, com o objetivo de praticar os fundamentos da programação e desenvolver minha lógica computacional.

## Conteúdos praticados

### 1. Condicionais
- Maior entre três números.
- Verificação de empréstimo.
- Cálculo de peso ideal.
- Média e aprovação.
- Calculadora utilizando switch.

### 2. Cálculos e operações
- Cálculo de salário por horas trabalhadas.
- Descontos e salário líquido.
- Cálculo de área e quantidade de tinta.
- Cálculo de combustível.
- Conversão de segundos em horas, minutos e segundos.
- Divisão de conta de restaurante.

### 3. Laços de repetição
- Soma de números pares.
- Exibição de números entre dois valores.
- Média de números ímpares.
- Estruturas while e for.

### 4. Vetores e funções
- Soma de números pares em um vetor.
- Identificação do maior e menor número.
- Cálculo de dobro utilizando função.
- Calculadora com funções.
- Controle de vendas semanal.
- Organização de números em ordem inversa.
- Cálculo de descontos.
- Controle de aprovação.
- Identificação de números repetidos.

### 5. Matrizes
- Diagonal principal.
- Soma de matrizes.
- Triângulo superior de uma matriz.

## Tecnologias utilizadas
- Linguagem C
- Visual Studio Code

## Objetivo

Praticar lógica de programação, estruturas condicionais, estruturas de repetição, vetores, matrizes e funções, desenvolvendo conhecimentos fundamentais para minha formação na área de tecnologia.
