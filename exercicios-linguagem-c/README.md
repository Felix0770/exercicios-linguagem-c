# Exercícios de Programação em C

Repositório com exercícios e atividades desenvolvidos durante meus estudos de programação em linguagem C, no curso de Banco de Dados.

Os códigos estão separados por assunto para facilitar a leitura e a consulta.

## Organização

- **01-condicionais:** estruturas `if`, `else` e `switch`.
- **02-calculos:** cálculos matemáticos, operações e entrada e saída de dados.
- **03-lacos-de-repeticao:** estruturas `for` e `while`.
- **04-vetores-e-funcoes:** vetores, funções e processamento de dados.
- **05-matrizes:** matrizes bidimensionais e operações com seus elementos.

## Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída com `printf` e `scanf`
- Operadores aritméticos e relacionais
- Estruturas condicionais
- Estruturas de repetição
- Vetores
- Matrizes
- Funções
- Cálculos e resolução de problemas

## Como executar

Cada arquivo `.c` é um programa independente e possui sua própria função `main`.

Com um compilador GCC instalado, entre na pasta do exercício e execute:

```bash
gcc nome-do-arquivo.c -o programa
./programa
```

No Windows, execute:

```bash
gcc nome-do-arquivo.c -o programa.exe
programa.exe
```

O exercício de compra de tinta utiliza a biblioteca matemática `math.h`. No GCC, compile esse arquivo com:

```bash
gcc 04-compra-de-tinta.c -o programa -lm
```

## Objetivo

Praticar lógica de programação e desenvolver conhecimentos fundamentais da linguagem C por meio de exercícios acadêmicos e atividades de sala.
